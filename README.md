# Everybody Codes

My solutions to [Everybody Codes](https://everybody.codes) puzzles, in Python.

## Layout

```
solutions/e<event>/q<NN>.py     # one file per quest, parts 1-3
inputs/<event>/q<NN>_p<N>.txt   # personal puzzle notes (not committed)
```

## Run

```bash
python run.py 2026 1        # event 2026, quest 01, all parts
python run.py 2026 1 -p 2   # part 2 only
```

Puzzle inputs are personal and kept out of the repo (see `.gitignore`).
